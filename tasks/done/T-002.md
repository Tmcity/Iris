## 6. 实现要求

### 6.1 AppPaths（Iris.Infrastructure/Storage）

```csharp
// 签名要求（实现由你完成）
internal sealed class AppPaths : IAppPaths
{
    internal const string PortableMarkerFileName = "portable.txt";
    internal const string AppFolderName = "Iris";

    /// <param name="executableDirectory">exe 所在目录（生产环境为 AppContext.BaseDirectory）。</param>
    /// <param name="roamingAppDataDirectory">%APPDATA%（生产环境为 Environment.SpecialFolder.ApplicationData）。</param>
    internal AppPaths(string executableDirectory, string roamingAppDataDirectory);
}

public static class AppPathsFactory
{
    /// <summary>生产环境入口。在 DI 容器建立之前调用（日志需要最先初始化）。</summary>
    public static IAppPaths CreateDefault();
}
```

规则：
1. `executableDirectory` 下存在 `portable.txt`（文件名不区分大小写）→ `IsPortable = true`，`DataDirectory = {executableDirectory}\data`；否则 `DataDirectory = {roamingAppDataDirectory}\Iris`。
2. 文件路径：`SettingsFile = DataDirectory\settings.json`，`SecretsFile = DataDirectory\secrets.dat`，`DatabaseFile = DataDirectory\history.db`，`LogDirectory = DataDirectory\logs`。所有路径都是经过 `Path.GetFullPath` 规范化的绝对路径。
3. 构造函数中创建 `DataDirectory` 与 `LogDirectory`（已存在时不报错）。
4. 目录创建失败（IO / 权限异常），或 `roamingAppDataDirectory` 为空字符串（且不是便携模式）→ 抛出 `IrisException(ErrorCode.StorageFailure, "无法创建数据目录", innerException, detail: <目标路径>)`。
5. 属性全部只读，构造后不再访问磁盘。

### 6.2 IrisLogging（Iris.App/Hosting）

```csharp
internal static class IrisLogging
{
    /// <summary>创建日志器。levelSwitch 初始级别为 Information。</summary>
    public static Serilog.Core.Logger CreateLogger(IAppPaths paths, Serilog.Core.LoggingLevelSwitch levelSwitch);

    /// <summary>把 GeneralSettings.LogLevel 字符串（Verbose/Debug/Information/Warning/Error，不区分大小写）解析为 LogEventLevel。</summary>
    public static bool TryParseLevel(string? value, out Serilog.Events.LogEventLevel level);
}
```

Serilog 配置（原样执行）：
- `MinimumLevel.ControlledBy(levelSwitch)`，`Enrich.FromLogContext()`
- `WriteTo.File(path: Path.Combine(paths.LogDirectory, "iris-.log"), rollingInterval: RollingInterval.Day, retainedFileCountLimit: 7, fileSizeLimitBytes: 10 * 1024 * 1024, rollOnFileSizeLimit: true, encoding: UTF8（无 BOM）, outputTemplate: "{Timestamp:yyyy-MM-dd HH:mm:ss.fff zzz} [{Level:u3}] ({SourceContext}) {Message:lj}{NewLine}{Exception}")`
- 按天滚动后的文件名形如 `iris-20260925.log`，与 ARCH §12.1 一致。
- Debug 构建时额外加 `WriteTo.Debug()`（需要 `Serilog.Sinks.Debug` 包——**可选**；如果添加，请写入 `Directory.Packages.props` 并在报告中说明）。

### 6.3 App.xaml.cs 接入

- 重写 `OnStartup`：
  1. `IAppPaths paths = AppPathsFactory.CreateDefault();`，捕获 `IrisException` → `MessageBox.Show($"{ex.Message}\n{ex.Detail}", "Iris", MessageBoxButton.OK, MessageBoxImage.Error)`，然后 `Shutdown(1)` 并 return。
  2. 创建 `LoggingLevelSwitch`，`Log.Logger = IrisLogging.CreateLogger(paths, levelSwitch)`。
  3. 输出一行启动日志（Information，结构化模板）：版本号（`Assembly.GetEntryAssembly()` 的 InformationalVersion）、`paths.DataDirectory`、`paths.IsPortable`、`Environment.OSVersion`、`RuntimeInformation.FrameworkDescription`。
  4. 调用 `base.OnStartup(e)`。
- 重写 `OnExit`：输出一行退出日志（包含 `e.ApplicationExitCode`），然后 `Log.CloseAndFlush()`，最后调用 `base.OnExit(e)`。
- `LoggingLevelSwitch` 暂时保存在 `App` 的私有字段中，T-005 会把它交给 Host。

**`LogText`**（命名空间 `Iris.Core.Diagnostics`）：

```csharp
public static class LogText
{
    /// <summary>Information 及以上级别使用。格式：len=<字符数> sha=<SHA-256 前 8 位小写十六进制>；null 或空串返回 "len=0"。</summary>
    public static string Fingerprint(string? text);

    /// <summary>仅限 Debug 级别使用。格式：Fingerprint + ' head="<前 32 个字符>"'，超过 32 个字符时末尾加 "…"。</summary>
    public static string Preview(string? text);
}
```

- SHA-256 基于 UTF-8 字节计算（使用 `SHA256.HashData`，不要创建 `SHA256` 实例）。
- Preview 中的 `\r`、`\n`、`\t` 分别替换为字面量 `\r`、`\n`、`\t`（保证日志单行）；`"` 替换为 `\"`。
- 截断不得拆开代理对：如果第 32 个字符是高位代理项，就只取前 31 个字符。
- `len` 统计的是 `string.Length`（UTF-16 码元数）。
