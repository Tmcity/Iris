# T-038 英文资源语义复核

前架构对话已对基础App、通用迁移及Core错误的候选英译逐条核对，原候选与复核记录保留在本目录。接续后核对新增的预设标签、无障碍名称、日志等级和非法界面语言提示；自动检测、繁体及简体中文选项的英文调整保持原含义，值见 `supplemental-reviewed.json`。

预设标签仅按稳定Key用于新增菜单，不改已保存或用户命名；日志等级只更换展示文本，不改变存储标记；无障碍名称区分源语言、目标语言和原文；非法语言提示保持允许值。三个语言选项的新英文仅为完整显示而调整措辞，翻译目标代码和用户文本保持。

运行 `python verify_reviewed_resources.py F:/Iris` 可将当前英文资源与已实际审阅的文本快照逐键比较；脚本遇到未审阅、改动或缺失项退出非零。完整资源键、复合格式解析、编译资源与源码一致性另由正式审计验证，本脚本不替代布局或运行验证。
