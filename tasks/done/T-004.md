## 1. 背景

API Key、百度 Secret Key 等凭据不能放进 settings.json（ADR-07）。本工单实现 `ISecretStore`：用 Windows DPAPI（当前用户范围）加密后存进 `secrets.dat`。密钥存储的要求比设置更严：**任何情况下都不能丢失有效的密钥文件，任何日志都不能出现密钥**。

完整规范已写进 **ARCH v1.4 §12.3**，`ISecretStore` 的契约注释也已同步更新。本工单严格按这两处实现。

另外包含 T-003-R1 复审时发现的 2 项小遗留（第 6.5 节）。

3. 提供 `AddIrisPlatformWindows()` DI 扩展方法。

## 6. 实现要求

### 6.1 AtomicFile 同步方法

```csharp
/// <summary>WriteAllBytesAsync 的同步版本，语义完全相同（tmp + WriteThrough + Flush(true) → 可选备份 → Move）。</summary>
public static void WriteAllBytes(string path, ReadOnlyMemory<byte> content, string? backupPath);

/// <summary>MoveAsync 的同步版本。</summary>
public static void Move(string sourcePath, string destinationPath, bool overwrite);
```
- 参数用 `ReadOnlyMemory<byte>` 而不是 `ReadOnlySpan<byte>`：span 是 ref struct，不能被重试用的 lambda 捕获，会直接编译失败。
- 重试策略与异步版本相同（5 次、间隔 50 ms，改用 `Thread.Sleep`）；判断“是否为共享冲突”的 `IsTransient` 两边共用。同步与异步版本放在相邻位置、结构保持一致，不要写出两套不同的流程。
- 失败 → `IrisException(StorageFailure)`，并尽力删除 tmp。

### 6.2 SecretsFileCodec（纯逻辑，不涉及 DPAPI）

```csharp
internal static class SecretsFileCodec
{
    public const string Format = "iris-secrets";
    public const int Version = 1;

    /// <summary>解析 secrets.dat 的字节。不抛异常：格式问题通过返回值表达。</summary>
    public static SecretsFileParseResult Parse(ReadOnlySpan<byte> utf8Json);

    /// <summary>按键名序数排序写出；UTF-8 无 BOM、缩进、末尾换行。</summary>
    public static byte[] Serialize(IReadOnlyDictionary<string, byte[]> encryptedEntries);
}

internal sealed record SecretsFileParseResult(
    IReadOnlyDictionary<string, byte[]> Entries,   // 键 → DPAPI 密文（已从 Base64 解码）
    bool IsCorrupted,                              // true：整个文件不可用，需要做损坏备份
    IReadOnlyList<string> DroppedKeys);            // 被单独丢弃的条目（只有键名）
```
- 解析：`JsonDocument.Parse(..., new JsonDocumentOptions { AllowDuplicateProperties = false })`（重复属性在解析阶段就会抛 `JsonException`，架构师已实测确认）。
- 以下情况 `IsCorrupted = true`：语法错误 / 重复属性、根节点不是对象、`format` 不等于 `"iris-secrets"`、`version` 不是整数 1、`entries` 缺失或不是对象。
- 单个条目：键为空白、值不是字符串、值不是合法 Base64（`Convert.FromBase64String` 抛 `FormatException`）→ 放入 `DroppedKeys` 并跳过（空白键名在 `DroppedKeys` 中记为 `"(空键名)"`）。

### 6.3 DpapiSecretStore

```csharp
internal sealed partial class DpapiSecretStore : ISecretStore
{
    public DpapiSecretStore(IAppPaths paths, TimeProvider timeProvider, ILogger<DpapiSecretStore> logger);
}
```
严格按 ARCH §12.3 实现，要点：
1. 状态：`Dictionary<string, byte[]> _entries`（只存密文）、`bool _degraded`、`HashSet<string> _decryptWarned`；用 `System.Threading.Lock` 保护。
2. 构造时加载：文件不存在 → 空；按 `AtomicFile` 的重试策略读取字节，仍失败 → 降级；`Parse` 结果为损坏 → `AtomicFile.Move` 到 `secrets.corrupt-{yyyyMMddHHmmss}.dat`（时间取 `timeProvider.GetLocalNow()`，重名追加 `-1`……），移动失败 → 降级；`DroppedKeys` 逐个记 Warning（只记键名）。**不要在构造函数中解密。**
3. `Get(key)`：`ArgumentException.ThrowIfNullOrWhiteSpace(key)`；在锁内取出密文后，在锁外调用 `ProtectedData.Unprotect(cipher, Entropy, DataProtectionScope.CurrentUser)`；`CryptographicException` → 返回 null，同一个键只记一次 Warning。
4. `Set(key, value)`：校验参数；空字符串 → 转为 `Remove`；在锁外加密（`ProtectedData.Protect`，entropy 为 `"Iris.Secrets.v1"u8`，定义成 `private static ReadOnlySpan<byte>` 属性或 static readonly 数组）；进锁：若处于降级模式，先尝试重新加载一次（失败 → `SecretUnavailable`）→ 复制字典并写入新条目 → `SecretsFileCodec.Serialize` → `AtomicFile.WriteAllBytes(path, bytes, backupPath: null)` → 成功后才替换 `_entries`，并把该键从 `_decryptWarned` 中移除；出锁后触发 `Changed(key)`。
5. `Remove(key)`：键不存在 → 返回 false（不写盘、不触发事件）；其余流程同 `Set`。
6. `Changed`：出锁后触发；逐个调用处理器（`GetInvocationList()`），异常分别捕获并记 Error。
7. 日志：`LoggerMessage` 源生成；只允许出现键名与文件路径。**不得出现值、密文、Base64 串。**
8. 不实现 `IDisposable`（没有需要释放的资源）。
