## 3. 强制边界与验证

- hook 只做规范批准的有界元数据快照及非阻塞入队；move 不查询桌面；任何路径继续 CallNextHookEx，绝不吞用户输入或在回调写日志/调用订阅者。
- 队列上限 256，过载/超龄/乱序 reset 并失效，不能拼出假手势。来源、I 型/Shift、系统双击时空矩形、uint 回绕及极端坐标均按正式规则。
- 所有异步启动/停止/发布责任同步登记；预取消不废弃旧 run；迟到 HHOOK 必须回收；Stop 等全部 native/订阅/consumer/thread 真正退出。失败保留所有权可重试，不能清句柄假报成功。
- Generation 与每次事件参数对应；B 将据此拒绝旧 UI 排队事件。发布回调在后台锁外执行，某订阅者失败不跳过其它清理。

## 5. 开发实施报告（2026-10-05，请求复审）

上方保留签发工单全文。开发基线为 141abec5920588dba371d1d6495077c3a7b37ed7；本报告不代表架构师验收或 T-024/A 结案。

实现 Core 的 CCR-020 精确端口同步；新增 Platform.Windows/Hooks 下 MouseSelectionMonitor、GestureRecognizer、NativeMouseAdapter、Win32MouseHookApi 及内部值模型/OS 边界；DI 惰性单例注册和对应 CsWin32 声明。没有 App 入口、图标、鼠标设置、选区读取、Clipboard/UIA/Keyboard 调用或 T-024B/T-025 实施。

Start 在调用返回任务前冻结选项、登记首次 run 身份和托管责任；预取消/非法选项不影响旧 run。重启先失效并完整停止旧 run，再以不同代次创建新 run；Start/Stop 并发明确拒绝新的启动，停止共享在途清理。线程创建、安装与消费均在后台；线程先建立消息队列，再取得共享 IDC_IBEAM 并安装 WH_MOUSE_LL。取消和立即 Stop 不遗忘尚未返回的安装。

Hook 仅复制 MSLLHOOKSTRUCT 的消息、坐标、时间和注入 flags；button down/up 查询按规范限定，move 不查询桌面。nCode<0 不解引用数据；异常路径同样尝试 CallNext。队列容量 256、非阻塞 TryWrite、禁止同步 consumer continuation；丢失 epoch 残余先丢弃，再合并失效通知，要求新的 clean down。250ms 超龄、uint 倒序、来源和注入检查均在实际消费链执行，查询后再次验证时效与 epoch/发布身份。

识别器只接受冻结配置与值输入；Drag 使用 Int128 平方和保留最大位移，Shift 在 down 捕获，双/三击使用系统 DPI 指标及总宽高半开矩形，第四击重起序列。来源事件清除 WindowTitle；排除进程按原始字符串 OrdinalIgnoreCase 匹配，不 Trim 或变换扩展名。公开 ToString 仅保留安全状态。

Stop 同步撤销资格、异步等待订阅者/consumer/native callback/真实消息线程退出；ThreadExited 信号之后仍 Join 实际线程。卸载失败保留 HHOOK/delegate，投递失败保留线程与已卸载事实，重试不重复成功的卸载。运行故障与清理故障分别保留固定阶段及数值；正常 Stop 期间发生的迟到消息泵/consumer 故障也报告，已交付的历史故障不在成功重试后重复抛出。同步 Dispose 在未完整停止时拒绝，DisposeAsync 可重试清理并禁止后续启动。
