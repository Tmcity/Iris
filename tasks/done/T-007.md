## 1. 背景

原文在发给大模型之前，要经过两步处理：
1. **预处理**：统一换行、去掉看不见的字符、压缩空行。划词翻译时，还要把网页或 PDF 中被硬换行截断的句子接回来。
2. **套用 Prompt 模板**：把语言名和原文填进模板。

这两步都是 `Iris.Core` 中的纯逻辑。规则写在 **ARCH v1.8 §7.4 与 §7.5**，契约中 `ITextPreprocessor`、`IPromptRenderer`、`IPromptTemplateProvider`、`OcrTextLayout.MergeParagraphs` 的注释也已同步更新。

特别说明两条安全与正确性要求（原因都写在 ARCH 中，务必先读）：
- **Prompt 必须单遍替换**：否则原文中的 `{{target_language}}` 会被二次替换，形成模板注入。
- **不得删除 U+200C / U+200D**：否则组合 emoji 会被拆散，波斯语、印地语的文本会被破坏。

## 6. 实现要求

### 6.1 UnicodeScripts（从 T-006 的检测器中提取）

```csharp
internal enum UnicodeScript { Other, Kana, Hangul, Han, Cyrillic, Thai, Arabic, Latin }

internal static class UnicodeScripts
{
    /// <summary>码点范围严格按 ARCH §7.3.2 的表格。</summary>
    public static UnicodeScript Classify(Rune r);

    /// <summary>ARCH §7.5 中“CJK”的定义：汉字、假名、U+3000–303F、U+FF00–FFEF。谚文不算 CJK。</summary>
    public static bool IsCjkForLineMerge(Rune r);
}
```
- 把 `ScriptLanguageDetector` 中的 `Script` 枚举和 `Classify` 方法**原样搬过来**，检测器改为调用它。**纯重构**：T-006 的检测器测试必须一行不改、全部通过。
- 注意：U+FF00–FFEF 与拉丁全角字母（FF21–FF3A、FF41–FF5A）、半角片假名（FF66–FF9F）有重叠。`IsCjkForLineMerge` 的判断**独立于** `Classify` 的结果，只要码点落在 U+FF00–FFEF 内就返回 true。

### 6.2 SoftLineBreakMerger

```csharp
internal static class SoftLineBreakMerger
{
    /// <summary>
    /// 按 ARCH §7.5“软换行合并”规则合并 lines。空行（长度为 0）作为段落分隔保留。
    /// isParagraphBreakAfter(i) 返回 true 表示第 i 行之后必须保留换行（OCR 用；文本预处理传 null）。
    /// 返回用 '\n' 连接的结果。
    /// </summary>
    public static string Merge(IReadOnlyList<string> lines, Func<int, bool>? isParagraphBreakAfter = null);
}
```
- 列表标记的两个正则写成 `[GeneratedRegex]` 源生成的静态成员。
- 句末标点、收尾符号用 `SearchValues<char>` 或 `FrozenSet<char>`，内容与 ARCH **完全一致**。
- 比较字符的脚本时按 `Rune` 处理：A 的“最后一个字符”要用 `Rune.DecodeLastFromUtf16` 取出，避免把代理对拆开。

### 6.3 TextPreprocessor

构造函数：`(ISettingsService settings)`。严格按 ARCH §7.5 的 6 个步骤实现；每次调用都读取 `settings.Current.Translation.SelectionLineBreaks`。

### 6.4 PromptRenderer 与 PromptFingerprint

- `PromptRenderer`：构造函数 `(ILanguageCatalog catalog)`。单遍替换严格按 ARCH §7.4：
  - 正则用 `[GeneratedRegex(@"\{\{([a-z_]+)\}\}")]`。
  - **必须使用 `MatchEvaluator` 重载**。使用字符串替换重载的话，原文中的 `$&`、`$1` 会被当作替换模式解析。
  - 占位符区分大小写（`{{TEXT}}` 属于未知占位符，原样保留）。
- `PromptFingerprint.Compute(PromptTemplate template) : string`：严格按 ARCH §7.4（SHA-256，UTF-8 编码，`System + "\u0000" + User`，取前 16 位小写十六进制；使用 `SHA256.HashData`）。

### 6.5 PromptTemplateProvider

- 构造函数：`(ISettingsService settings, ILogger<PromptTemplateProvider> logger)`。严格按 ARCH §7.4 的“模板查找”与“模板有效性”规则。
- “每个 Id 只记一次 Warning”：用 `ConcurrentDictionary<string, byte>`（`StringComparer.OrdinalIgnoreCase`）记录已经警告过的 Id。日志中只写模板 Id，不写模板内容。
- 内置模板集合目前只有 `BuiltInPrompts.Default`，写成一个 `FrozenDictionary`，方便以后扩展。

### 6.6 T-006 评审遗留（代码质量）

- **C6-1**：`ScriptLanguageDetector` 中定义的 8 个 double 阈值常量**都没有被使用**，实际比较用的仍然是 `5`、`30`、`50`、`70`、`15`、`3` 等字面量。改为整数百分比常量（如 `private const int KanaThresholdPercent = 5;`），比较语句中引用这些常量；删除没有用到的 double 常量。`EnglishLongTextMinWords = 3` 同样要定义成常量。
- **C6-2**：`LanguageCatalog.All` 直接返回内部的静态数组，调用方可以把它强转回 `LanguageInfo[]` 然后修改，从而污染全局数据（架构师已验证 `catalog.All is LanguageInfo[]` 为 true）。改为返回 `ReadOnlyCollection<LanguageInfo>`（在静态字段中创建一次），并增加测试 `All_IsNotMutableArray`。
- **C6-3**：按 ARCH v1.8 §7.3.2，短语规则允许词内的 `’`（U+2019）。增加测试：`"don’t"` → en（置信度 0.6）。

### AC-5：安全（PromptRenderer.cs 完整源码）

```csharp
using System.Text.RegularExpressions;
using Iris.Core.Languages;

namespace Iris.Core.Translation;

internal sealed partial class PromptRenderer : IPromptRenderer
{
    private readonly ILanguageCatalog _catalog;

    public PromptRenderer(ILanguageCatalog catalog)
    {
        _catalog = catalog;
    }

    [GeneratedRegex(@"\{\{([a-z_]+)\}\}")]
    private static partial Regex PlaceholderRegex();

    public RenderedPrompt Render(PromptTemplate template, ProviderTranslateRequest request)
    {
        var sourceName = _catalog.GetPromptName(request.SourceLanguage);
        var targetName = _catalog.GetPromptName(request.TargetLanguage);

        string Evaluator(Match match)
        {
            var placeholder = match.Groups[1].Value;
            return placeholder switch
            {
                "source_language" => sourceName,
                "target_language" => targetName,
                "text" => request.Text,
                _ => match.Value,
            };
        }

        var renderedSystem = PlaceholderRegex().Replace(template.System, Evaluator);
        var renderedUser = PlaceholderRegex().Replace(template.User, Evaluator);

        return new RenderedPrompt(renderedSystem, renderedUser);
    }
}
```
