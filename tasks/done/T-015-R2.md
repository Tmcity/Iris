## 三、修改明细与关键实现

### 1. `src/Iris.App/Translation/TranslateWindowOperation.cs`
- 增加 `_activeCancelCallbacks` 字段，并在 `CancelAsync` 启动取消核心前增加计数，在 `finally` 块中减少计数并触发退休判定（`TryMarkRetiredLocked`）；
- `CancelAsync` 移除外层 `Task.Run`，直接返回 `ExecuteCancellationCoreAsync()` 任务并在无锁状态下执行 `await _cts.CancelAsync()`；
- `TryMarkRetiredLocked` 统一检查：`!_hasCallerOwnership && !_hasTryShowOwnership && !_hasSessionOwnership && _activeWorkCount <= 0 && _activeCancelCallbacks <= 0`。在回调完全执行前操作绝不退休，彻底杜绝回调挂起期间操作提前回收导致的 CTS 提早释放。

### 2. `src/Iris.App/Translation/TranslateWindowPresenter.cs`
- `TryShowAsync` 在调用 `ApplyPlacement` 与窗口展示时使用 `try-catch` 包裹。当发生异常时，安全撤销 VM 操作（`_viewModel?.RevokeOperation(op.Id)`），调用 `op.Cancel()` 取消已启动的工作，记录安全日志 `LogShowFailed(_logger, ex.GetType().Name)`，并安全返回 `false`（不再 rethrow），确保调用方得到准确的失败反馈且不遗留未撤销的发布所有权；
- 依赖注入 `INativeWindowPlacementAdapter`，并在窗口发生 DPI 变更时调用 `ReconstrainWindowPlacement()` 重新应用屏幕限制。

### 3. `src/Iris.App/Translation/TranslateWindowViewModel.cs`
- `SubmitMainTranslation` 在提交主翻译时，原子初始化状态与自动复制资格：`IsTranslating = true; Cards.Clear(); StatusMessage = null; Error = null;`，重置 `_sessionOriginalText = text; _sessionOrigin = origin; _sessionAutoCopyMode = _settingsService.Current.Translation.AutoCopy; Interlocked.Exchange(ref _autoCopyClaimed, 0);`；
- `ApplyRequest` 仅在 `isNewMain` 成立时初始化自动复制资格，对于阶段性状态更新不重复重置 `_autoCopyClaimed`，防止单主请求多次触发自动复制；
- `RunMainTranslationAsync` 在 `!operation.IncrementWork()` 时通过 `_uiDispatcher` 将 `IsTranslating = false`；在获取工作计数后全程置于 `try-finally` 中，确保任何中间异常均重置状态与清理资源；
- `OnWindowHidden()` 同步将 `IsTranslating = false`（通过属性 setter 触发 PropertyChanged 与命令 `RaiseCanExecuteChanged`），并将流式卡片置为 `SetCanceled()`，使得隐藏重开后按钮状态正确恢复；
- `CancelPendingAndActiveCopies` 与 `TrackCopy` 采用 `CancelAsync()` 异步取消，移除外层 `Task.Run`；
- 所有 `[LoggerMessage]` 移除 `Exception ex` 参数，仅记录安全类名；错误信息统一经 `SanitizeErrorInfo` 脱敏；
- 长度校验采用 `_textPreprocessor.Prepare` 后的实际长度。

### 4. `src/Iris.App/Translation/WindowPlacementHelper.cs`
- `FindNearestMonitor` 使用 `Int128` 计算平方和距离，杜绝坐标差值平方乘法溢出，且严格遵循在距离并列时选取首个显示器。

### 5. `tests/Iris.App.Tests/Translation/TranslateWindowUiTests.cs`
- 针对 WPF UI 测试环境，将服务注册中的 `ImmediateUiDispatcher` 替换为真实的 `WpfUiDispatcher`，确保后台任务对 `ObservableCollection` 的修改正确调度到 WPF STA 线程，避免跨线程并发修改异常。

## 四、与工单的偏差说明

1. **`TranslateWindowUiTests` 调度适配**：
   - 原测试注册中使用了 `ImmediateUiDispatcher`。在测试涉及后台异步枚举与管道时，`ImmediateUiDispatcher` 会在 ThreadPool 线程上直接执行 UI 回调，触发 WPF `CollectionView` 的跨线程集合变更异常（`System.NotSupportedException`）导致主工作提前异常终止。
   - 现将其更改为对接真实 WPF STA 调度器的 `WpfUiDispatcher`，使 UI 行为与真实运行环境保持完全一致。
2. **`TranslateWindowViewModelTests.SubmitMain_InputExceedsMaxInputChars_SetsErrorAndDoesNotEnqueue` 异步化**：
   - 测试方法由 `void` 改为 `async Task`，并在断言后执行 `await vm.WaitForActiveWorkAsync()`，确保协调任务完成且无残留工作。
