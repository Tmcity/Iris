## 1. 交付范围

- NativeMethods.txt 仅增加必要 API，沿用 Windows SDK/CsWin32，不增 NuGet 包，不引入 WPF/WinForms 或 App 调度依赖。

## 2. 关键执行规则

1. 设备表与显示器按运行时设备名关联，保留 attached 且非 mirror 的项；不要误删正常 remote/virtual 桌面。每次返回新的只读快照，不发布不完整关联结果。
2. 不一致快照最多重采一次，仍失败按 Unknown 报告；不伪造主屏、矩形或 1.0 DPI。不增加长期缓存/显示拓扑监听框架。
3. 物理像素、负坐标、WorkArea、几何范围校验遵守规范；GetMonitorAt 从同一快照按整数像素最短距离选取，平方和用 Int128，并列主屏/DeviceName 稳定排序。
4. 同步原生帧临时设置 PerMonitorV2 thread context；通过目标显示器上的不可见 top-level 窗口取得 GetDpiForWindow，验证归属，销毁自身 HWND 并恢复旧 context。期间不 await、不改全局 DPI、不显示或激活窗口。
5. GetPhysicalCursorPos 只读光标。GetForegroundApp 处理空前台、PID 输出不变、权限拒绝、退出与窗口切换；只返回实际映像文件名，标题有界且可空，最终重验 HWND/PID。无法确认来源时返回 null，不拼接两个窗口的数据。
6. 进程句柄、HWND 和 context 在成功/失败/null 路径均完整清理。执行主失败优先，其后清理错误安全记录；无主失败时首个清理失败成为主失败。不要复制早期剪贴板中遗漏第二个错误的模式。
7. 固定错误文案及日志边界见 DESKTOP_CONTEXT.md §4；不记录窗口标题/完整路径/整个返回对象或原始异常链。查询层不通知用户、不申请提权。

## 3. 验收与有区分力的回归

测试必须驱动实际实现，调用记录来自真实执行的 fake API，不用手写列表自验。

| 场景 | 必须证明 |
|---|---|
| attached/mirror/remote，名称大小写和关联缺失 | 正确筛选/关联，不把正常远程桌面删掉；不一致最多重采一次 |
| 原生缓冲及返回集合尝试外部修改 | 已发布快照不受后续调用/别名修改影响 |
| 负坐标、共边界、空隙、重叠、并列 | 半开区间/整数距离/稳定选择一致，不依赖枚举顺序 |
| 极端 int 坐标、非法尺寸、NaN/Infinity/零 DPI | 无溢出、无默认值伪成功；可用小布局逐像素基准作独立比对 |
| 创建 HWND/DPI 查询/归属校验/销毁/context 恢复失败 | 退出有明确错误，自身资源清理，线程 context 恢复，无显示/激活操作 |
| 无前台、无效 HWND 保留旧 PID、权限拒绝、查询中切换 | 返回 null 或完整稳定快照，不拼接来源，不使用未初始化输出 |
| 同进程跨线程标题、长标题/路径、空 caption | 不跨线程 WM_GETTEXT 等待，固定缓冲/可空规则成立，不泄漏文本 |
| 主失败和清理失败组合 | 主错误保留，其余错误按 API/数值安全记录 |
| 实际 App 组合根 | 构建、解析、单例正确；构造不依赖实时桌面 |

实机验证只进行只读显示器/光标查询与不可见 DPI 窗口；不改用户的分辨率、缩放、排列或焦点，不自动读取用户窗口标题作为测试数据。前台查询用自有窗口/假端口验证。多屏/混合 DPI/RDP/热插拔若无环境，明确未验证，不把合成测试写成实机通过。

所有受控门闩和线程退出检查有上限与 finally 收尾。平台探针不能与引用相同项目的全量构建并发争用输出。报告不设测试数量指标，只列实际输出与证明范围。
