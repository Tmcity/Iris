## 3. 必须实现的行为

- 操作意图在异步读取之前获取；TryBeginOperation 的取消、关闭/容量拒绝、外来租约、Dispose/移交/调用方令牌语义按正式规范。全部尚未回收的操作状态最多 8 个，不能只统计有效会话。
- 对所有迟到结果/错误/UI 回调重新验证 (OperationId, ProviderId, RequestId)。用户编辑、隐藏、停止、新整窗意图使旧发布和自动复制资格失效，已启动的真实工作仍被观察。
- 全 Presenter 一个实际主调用、一个实际重试，各一个最新等待项；槽位覆盖枚举 DisposeAsync 和 App UI finally。新主等待旧会话主/重试完整退出。单卡重试不能清其它卡或取消仍在输出的服务。
- 正文/null/空字符串/加载/错误语义明确；空白/超限不联网。重试保存原始输入和主请求已解析语言，并使用当前服务配置，保持 BypassCache / RecordHistory 原规则。
- UI 正文/待刷缓冲/渲染快照/复制分别按规范计数；跨重试总预算不得漏算。唯一输出刷新回调跨会话共享；本地显示截断清楚标识，不能当成全文复制。Completed 清旧缓冲后用权威值覆盖。
- 自动复制只初始主请求首个有效完整结果；手动复制、取消、已进入原生提交阶段的边界按 CLIPBOARD_SERVICE.md。测试只用假 Clipboard。
- 顶栏、原文、语言选择/交换、翻译/停止、有序服务卡片、耗时/错误/缓存/截断、复制/重试/去设置完整接线。支持 IME，EnterToTranslate=false 为 Ctrl+Enter 翻译。保存服务排序后的卡片顺序在本单验收。
- 定位遵循物理坐标、SourceInitialized 后 SetWindowPos、目标屏 DPI、WorkArea 翻转/夹紧及 RememberLast 最新字段合并。只有本窗口使用窄 App 内部 HWND 适配器，无新包或公开平台契约。
