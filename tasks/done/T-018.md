## 1. 实现范围

- Core/Workflows/OpenSettingsHandler 及 Core DI 注册，依赖既有 ISettingsWindowPresenter；取消检查、可空页键转发按正式规范。
- App 的 SettingsWindow、ViewModel、SettingsWindowPresenter、internal 窗口会话/工厂与常规保存服务，必要的小型异步命令/VM 帮助代码及字符串资源。
- ThemeService 的预览所有权和迟到回调规则；托盘“设置”菜单启用并统一经 IActionDispatcher 派发。
- Platform.Windows/SystemIntegration/AutoStartService、窄注册表/路径测试边界及单例 DI。
- AppHostBuilder 注册、必要的 AppBootstrapper 正常退出接线和对应测试。纯 Core DI 测试可补 fake Presenter，不能因此引用 WPF/App。
- CCR-010 注释同步到 CONTRACTS.cs 与两个 Core 落地文件；只修改批准内容，不改公开签名、设置字段/默认值或错误码。

只开放 Theme、LaunchAtStartup、ShowStartupNotification、LogLevel。其它设置值保留，不开放无效果控件/空页面。不实现翻译服务页、密钥编辑、热键、翻译窗口或更新器；不增加 NuGet 包。

## 2. 窗口与组合根

Presenter 单例，首次 Show 才在 UI 创建一个独立 scope 的窗口会话，Closed 后释放；重复 Show 保留现有草稿，关闭再开新建。构造/Host.Build/解析托盘和 Dispatcher 时不创建 Window。

避免 Dispatcher → OpenSettingsHandler → Presenter → Dispatcher 的构造环；Presenter 用 UI 调度/按需工厂，窗口内依赖在后续 scope 中解析。不要从根容器解析 scoped ViewModel。pageKey 空/未知/尚未开放时回 general，不记录原始 key/Payload。

保存/预览/关闭回调绑定会话身份，旧回调不改新窗口或重开旧窗口。“取消”、X、Esc 放弃未保存内容；保存进行中暂不受理普通关闭，但 UI 消息循环不能被同步等待阻塞。

## 3. 保存、预览与系统应用

以 SETTINGS_EDITING.md 为完整语义，重点：

1. 编辑四个标量字段，固定 base/目标/dirty；不复制旧根配置覆盖 Current。保存时在 UpdateAsync 的 mutate 内检查最新值与基线冲突，仅合并脏字段。
2. 无 dirty 不写配置/注册表；目标已经持久化时不制造新版本。UI 验证使用既有合法主题/日志级别，不依赖 Normalize 静默替换用户无效输入。
3. 用 internal 结果区分未提交、已保存且应用完成、已保存但应用未完成。保存成功后的取消或注册失败不能说成未保存；重试应用不重写 JSON。
4. 主题选择只预览，取消恢复最新 Current；Changed/SystemEvents 执行时重算有效主题。旧会话不能撤销新预览，停止后的回调不再应用主题。
5. AutoStart 只管理约定的 HKCU Run/Iris 值；命令引用真实 apphost，不注册 dotnet.exe，不修改 StartupApproved，不在启动/打开窗口时自动重写。仅本次明确修改的启动意图触发保存后的幂等应用。
6. 注册表同步操作放后台，路径/命令/错误规则见正式规范。不读写真实凭据，日志和异常不包含可执行路径/注册表原值或原始异常链。

## 4. 正常退出的所有权

AppBootstrapper.StopAsync 在现有 StopSynchronousParts/Host 释放之前，等待内部设置 ShutdownAsync：禁止新会话/保存，取消提交前工作，观察已接纳的保存/应用实际退出，再关窗口并释放 scope/预览。

不可超时后直接销毁仍被使用的设置锁或会话；保存错误在边界观察后仍继续正常退出。系统注销/强制终止的既有同步路径不阻塞等待，不宣称已完成异步保存；不扩大为全局退出框架或更改 IAppLifetime 签名。

### 2.3 App 层
- **`ThemeService` 预览所有权扩展** (`src/Iris.App/Services/ThemeService.cs`):
  - 增加 `SetPreview(sessionOwner, theme)` 与 `ClearPreview(sessionOwner)`。
  - 维护 `_previewOwner` 与 `_previewTheme`；当前有效主题 `EffectiveTheme` 优先取 `_previewTheme`，其次回退至 `Current.General.Theme`。
  - 只有当前拥有预览权的会话才能清除该预览；外部设置变更或系统偏好变更事件在发生时重新计算当前有效主题，不覆盖活动预览。
  - 服务释放后清空预览并不再响应后续变更事件。
- **`GeneralSettingsSaveCoordinator`** (`src/Iris.App/Services/GeneralSettingsSaveCoordinator.cs`):
  - `Scoped` 生命周期，与窗口会话绑定。
  - 保存状态定义：`Uncommitted`（未提交/冲突/校验失败/提交前取消）、`SavedAndApplied`（配置已持久化且自启应用完成）、`SavedApplicationPending`（配置已持久化但自启注册等平台动作失败）。
  - 在 `_settingsService.UpdateAsync` 的 mutate 回调中检查冲突：当当前配置的已编辑字段既不等于草稿基线也不等于目标值时，抛出 `GeneralSettingsConflictException` 中断提交，保留用户草稿并返回冲突提示。
  - 增量合并：仅更新脏字段，严格保留未编辑字段与全部未在常规页暴露的配置（`UiLanguage`、`CheckForUpdates`、窗口位置、Provider Profiles 等）。
  - 自启应用：配置成功持久化越过提交边界后，不受调用方迟到取消影响；仅当本次明确编辑了 `LaunchAtStartup` 时触发 `AutoStartService.SetEnabled`。
  - 提供 `RetryAutoStartAsync`：重试应用时直接读取当前最新持久化的 `LaunchAtStartup` 意图，不重复写配置 JSON。
  - 支持 `CancelPreCommitWork()` 与跟踪 `ActiveWorkTask`，供优雅退出协调等待。
- **`SettingsViewModel`** (`src/Iris.App/Settings/SettingsViewModel.cs`):
  - 实现 `INotifyPropertyChanged`，暴露 4 个常规设置字段（`Theme`、`LaunchAtStartup`、`ShowStartupNotification`、`LogLevel`）。
  - 维护基线与目标快照，属性变更自动标脏并即时通过 `_themeService.SetPreview` 进行主题预览。
  - 异步命令与状态属性：`SaveCommand`、`CancelCommand`、`ReloadCommand`、`RetryAutoStartCommand`、`IsSaving`、`StatusMessage`、`IsConflict`、`CanRetryAutoStart`。
  - 取消与重载：取消时清除主题预览并请求关闭窗口；重载时将草稿还原至最新当前配置并清空脏状态与冲突标志。
  - 外部设置变更跟随：未编辑字段跟随最新设置静默更新基线与目标，已编辑字段保持用户编辑。
- **`SettingsWindow` WPF-UI 视图** (`src/Iris.App/Settings/SettingsWindow.xaml` + `.xaml.cs`):
  - 基于 WPF-UI `ui:FluentWindow`，遵循 PerMonitorV2 DPI 与 Windows 11 Fluent 视觉语言。
  - 左侧为当前支持的“常规”导航，右侧包含“外观与主题”（ComboBox）、“开机自启与通知”（CheckBox 卡片）、“日志级别”（ComboBox）。
  - 底部状态栏展示保存进度/成功提示/冲突警告及操作按钮（保存、取消、重试应用、重新载入）。
  - `x:ClassModifier="internal"`，确保遵循内聚性要求。
- **`SettingsWindowSession` & `SettingsWindowPresenter`** (`src/Iris.App/Settings/`):
  - `SettingsWindowPresenter` 单例实现 `ISettingsWindowPresenter` 与 `ISettingsShutdownCoordinator`。
  - 不在构造函数中创建任何 UI 窗口，避免依赖环。
  - `ShowAsync(pageKey)` 经 `IUiDispatcher` 调度至 UI 线程；首次调用在独立 `IServiceScope` 中创建会话并激活窗口；多次调用激活既有窗口并导航，复用草稿。
  - `pageKey` 规范化：null、空串、未知或尚未开放的页面统一定向到 `"general"`。
  - 窗口关闭事件触发会话 Dispose，清理主题预览并释放子 Scope。
  - `ShutdownAsync`：关闭窗口前调用 `CancelPreCommitWork()`，等待已接纳的后台保存任务退出，确保资源不被抢先销毁。
- **托盘与退出接线**:
  - `TrayIconController`：注入 `IActionDispatcher`，启用“设置…”右键菜单，点击后统一派发 `IrisAction.OpenSettings`。

  - `AppHostBuilder`：注册 `SettingsWindowPresenter`（单例）、`GeneralSettingsSaveCoordinator`（Scoped）、`SettingsViewModel`（Scoped）、`SettingsWindow`（Transient）。
