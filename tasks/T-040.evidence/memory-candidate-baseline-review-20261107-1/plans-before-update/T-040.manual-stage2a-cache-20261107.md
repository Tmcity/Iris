# T-040后续分段2A：缓存与卡片重试

前一段两行粘贴截图及完整GC后的45秒托盘样本核对完成后，才执行本段；目前仅准备材料。沿用同一正式0.2.10、T040 OpenAI fixture和原输入，不修改服务、语言或Prompt，以保持缓存键条件。

1. 从托盘打开输入翻译，输入与第一条历史完全相同的 `Iris T040 input 01`，点击“翻译”一次，等待完成。结果应为 `Iris T040 synthetic translation`，卡片出现“缓存”标记。
2. 用C:\IrisT040Features\Capture-Feature-View.cmd手工截图该卡片，再运行Save-Feature-State.cmd。此处保存单独的缓存时点，助手核对合成服务没有新增该文本请求，历史仍按仓储去重规则保存；相同文字本身不足以证明缓存。
3. 回该结果卡片，点击卡片中的“重试”一次，等待完成；该按钮也可用于已成功的终态卡片。结果正确后再次截图并保存。

实际入口不是一个独立“刷新”按钮；TranslateWindow.xaml绑定RetryCommand，中文资源为“重试”。OnCardRetry构造单卡请求时BypassCache=true、RecordHistory=false，所以本步期待新增网络请求并更新卡片，**不期待新增历史**。主“翻译”请求仍可写历史，二者须分别核对。

实际发执行步骤时请反馈第一次“缓存”是否可见、第二次“重试”是否完成及错误原文。窗口、输入、点击和截图均由用户完成，助手只读对照服务日志和历史快照。请求重试/取消与错误提示另外分段，避免多个行为的证据混在同一次保存中。
