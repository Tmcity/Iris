## 当前这一段的手工操作

1. 在来宾输入目录双击 `Enable-Signature-Diagnostic.cmd`。它只启用Sandbox的 `Microsoft-Windows-CAPI2/Operational` 事件日志，供定位此前微软MSI签名策略等待；不更改证书信任、TLS、代理或签名校验策略。若报错先保留原文并反馈。
2. 双击 `Iris-0.2.10-Official-Download.url`，下载并手工运行正式安装器，按安装器提示完成标准.NET依赖及Iris安装。不要手动预装.NET或预填下载缓存。记录大致安装用时、系统提示或错误。
3. 从Iris托盘打开设置，确认实际版本0.2.10。双击输入目录的 `Save-Installed-Diagnostic-State.cmd`，只读保存安装日志、微软MSI日志和最多2000条CAPI2诊断事件。
4. 关闭Iris设置/翻译/历史等功能窗口，只留托盘，空闲至少45秒；随后从托盘正常退出，等5秒，再从Iris快捷方式启动一次，再只留托盘空闲至少45秒。
5. 双击 `Save-Metrics-State.cmd` 保存观察器与当前产品状态。若报错保留原文，不重复安装或启动观察器。

反馈诊断是否启用、安装成功/失败、实际版本、总安装用时、两次启动/正常退出结果及错误原文。保留Sandbox和最后的托盘实例，后续再配置新的合成服务、产生T-040测试历史；新Sandbox不能直接解密旧Sandbox的DPAPI凭据。

这次原始数据用于区分安装器下载/证书链/MSI等待、Iris部署和应用冷启动；只有标准安装实际成功后才进入启动/内存/CPU判定。观察器同时记录内部bootstrap毫秒和进程创建到bootstrap完成的外部差值，每秒CPU/WorkingSet/PrivateBytes样本。30秒空闲读数不自动等同已证明稳态GC，GC证据尚需后续补充。
