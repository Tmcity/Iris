# 0.2.4 发布成功后的手工升级与卸载

当前 0.2.2 的安装、已保存启动检查开关及合成翻译/旧历史已核对。0.2.4 仍待单独发布确认；本主会话确认该版正式发布并核对资产后，再按以下步骤逐项操作。当前 Sandbox 和 0.2.2 保持运行。

保存入口：来宾 `C:\IrisAcceptanceUpgrade`。这个目录是同一本单 input 的新只读入口；只记录状态，不检查/下载/安装/卸载 Iris。所有输出仍写入 `C:\IrisAcceptanceOutput\session-1c8333f923744572ac2c71bab9576af5`，自动映射回宿主同名 output 会话。

| 步骤 | 用户操作 | 本段反馈 |
|---|---|---|
| 1 检查 | 设置→常规→检查更新，等显示 0.2.4 可用；双击 `Save-Offer-State.cmd` 保存，截更新状态图 | 是否显示 0.2.4；当前版本仍 0.2.2；系统提示或错误原文。本段停在可更新状态，等待复核 |
| 2 下载 | 收到下一步后点击下载更新，等到可安装/Ready；双击 `Save-Ready-State.cmd` 保存，截状态图 | 是否达到 Ready；当前仍 0.2.2；错误原文。本段停在 Ready，等待复核 |
| 3 安装 | 收到下一步后点击安装并重启，并在确认框确认；等待托盘重新出现，打开设置查看版本 | 显示版本应为 0.2.4；实际提示、是否正常回到托盘。继续完成下面的数据验证后保存 updated |
| 3 数据 | 打开历史，查看旧记录 `Iris acceptance check`；用原已保存合成服务翻译新文本 `Iris acceptance check after upgrade`，应返回 `Iris 公共升级验证`；双击 `Save-Updated-State.cmd` 保存，截版本/旧历史图 | 旧历史是否可读、原开关/服务是否保留、新翻译是否成功、错误原文。新文本用于形成独立请求，核对已保存 Key 在升级后仍可用 |
| 4 卸载 | 收到升级复核通过后，在来宾系统“已安装的应用”卸载 Iris，选择默认保留数据；完成后双击 `Save-Uninstalled-State.cmd`，再双击 `Stop-Manual-Evidence.cmd` | 是否卸载成功、提示或错误原文。保留 Sandbox 和输出，等本主会话核对最终进程/注册/快捷方式/用户数据及共享运行时后再关闭 |

每段反馈对应当前步骤即可；遇到错误保留窗口与原日志。版本截图只截 Sandbox 窗口，保存到该输出会话。各保存窗口会保留；若保存脚本报错，一并反馈错误原文。

本主会话负责只读核对检查未下载 full、下载未安装、真实退出与维护/native 顺序、正常应用仅重启一次、97 项正式安装载荷及保留数据、卸载项/快捷方式移除、共享 .NET 运行时保留。辅助生命周期探针和 Ready 记录不代替这些真实产品验收。C/父 T-039、T-040/NFR 仍待后续验收；M6/T-033 延期。
