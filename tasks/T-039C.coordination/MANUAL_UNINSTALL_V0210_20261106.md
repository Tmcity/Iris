# 0.2.10真实升级后：卸载并默认保留资料

已独立核对真正0.2.9→0.2.10界面升级：原5672正常exit0，原生Update.exe5516退出0并记录package applied successfully；6616/7456为Velopack hook，正常新进程只有8980。97正式载荷、版本截图、原配置/凭据、两条旧历史及新“Iris UI upgrade 0210”翻译均通过。原History警告保持，重启后的已采日志没有新的History操作警告。此结论不替代卸载验收。

在保留的同一Sandbox中由用户手工执行本段：

1. 打开Sandbox内Windows设置→应用→安装的应用（或应用和功能），找到Iris，点击卸载，确认系统卸载提示。
2. Iris维护窗口询问是否保留资料时，选择默认的“是 / Yes”，保留资料。等待卸载完成；记录系统提示或错误原文。
3. 关闭卸载完成提示，确认系统应用列表中Iris已移除。在来宾 `C:\IrisAcceptanceUninstall0210` 双击 `Capture-Uninstalled-V0210-View.cmd`，10秒内切回系统应用列表的Iris搜索结果，保留无Iris条目的状态。
4. 双击同目录 `Save-Uninstalled-V0210-State.cmd` 保存。它只读采集应用目录/资料目录、卸载注册项、快捷方式、运行时、进程与原日志；若采集报错，保留原文。
5. 反馈卸载成功/失败、是否选择保留资料、系统列表结果及错误原文。保留Sandbox、合成服务和记录器，等助手独立核对后再关闭。

这一步只卸载Sandbox内的Iris，共享.NET运行时保持。不要手工删除AppData资料目录。卸载后资料预计仍在当前用户APPDATA\Iris，助手会核对settings/secrets/history/logs及三条历史、正常进程退出、注册项/快捷方式/应用目录/事务状态。

维护工具为在安装目录之外运行而保留的自有副本和历史失败文件将单独记录，不会混同于仍安装的Iris；此类残留是否满足最终契约会在C/父任务复审中明确审计。原08:48失败和成功UI升级的原件完整保留。

C/父T039、T040/NFR和冷.NET安装性能未结案；本步骤完成后仍需独立复核实际终态，不能以用户反馈或安装成功直接结案。
