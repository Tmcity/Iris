# 0.2.6 正式发布后的手工升级与卸载

0.2.2 的正式安装、已保存启动检查开关、合成翻译和旧历史已核对。0.2.6 等待单独发布确认；本主会话确认正式发布并完成资产核对后，再逐段操作。当前 Sandbox 和 0.2.2 保持运行。

保存入口：来宾 `C:\IrisAcceptanceUpgrade`。输出仍在 `C:\IrisAcceptanceOutput\session-1c8333f923744572ac2c71bab9576af5`，自动映射回宿主原 output 会话。保存脚本只记录状态；只读记录器已恢复，实际产品操作仍由用户执行。

| 步骤 | 用户操作 | 本段反馈 |
|---|---|---|
| 1 检查 | 收到指令后，在设置→常规→检查更新，等显示 0.2.6 可用；双击 `Save-Offer-State.cmd` 保存，截更新状态图 | 是否显示 0.2.6、当前版本是否仍为 0.2.2、系统提示或错误原文；停在可更新状态等复核 |
| 2 下载 | 收到下一步后点击下载更新，等到可安装/Ready；双击 `Save-Ready-State.cmd` 保存 | 是否达到 Ready、当前是否仍为 0.2.2、错误原文；停在 Ready 等复核 |
| 3 安装 | 收到下一步后点击安装并重启，在确认框确认；等待托盘重新出现，打开设置查看版本 | 应显示 0.2.6；反馈实际提示和托盘是否正常返回，再完成下一行数据验证 |
| 3 数据 | 打开历史查看旧记录 `Iris acceptance check`；用原已保存合成服务翻译 `Iris acceptance check after upgrade`，应返回 `Iris 公共升级验证`；双击 `Save-Updated-State.cmd` 保存，截版本/旧历史图 | 旧历史是否可读、原开关/服务是否保留、新翻译是否成功、错误原文；新文本形成独立请求，用于核对保存的 Key 在升级后仍可用 |
| 4 卸载 | 收到升级复核通过后，在来宾系统“已安装的应用”卸载 Iris，选择默认保留数据；完成后双击 `Save-Uninstalled-State.cmd`，再双击 `Stop-Manual-Evidence.cmd` | 是否卸载成功、提示或错误原文；保留 Sandbox 和输出，等最终核对后再关闭 |

每段只反馈当前步骤。遇到错误保留窗口和日志；截图只截 Sandbox 窗口并保存到该输出会话。保存脚本若报错，一并反馈原文。

本主会话只读核对检查未下载、下载未安装、真实退出与维护/native 顺序、正常应用恰好一次重启、97 项正式安装字节和保留数据、卸载项/快捷方式移除、共享 .NET 运行时保留。辅助记录器探针和 Ready 不代替这些生产验收。C/父 T-039、T-040/NFR 仍待验收；M6/T-033 延期。
